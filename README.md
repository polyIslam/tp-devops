
# TP DevOps – Git, Maven et Docker

## Description
Ce projet consiste à développer une application REST avec Spring Boot,
à gérer son code avec Git et à la conteneuriser avec Docker.

## Technologies utilisées
- Java 17
- Spring Boot
- Maven
- Git et GitHub
- Docker

## Endpoints
- GET /hello : retourne un message de bienvenue.
- GET /version : retourne la version de l'application.
